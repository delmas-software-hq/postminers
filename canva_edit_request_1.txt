2. Delete Design (Delete Image & Data) :

http://127.0.0.1:8000/api/designs/<uuid:pk>/

Request Body: (None)

Postman Example: http://127.0.0.1:8000/api/designs/8e4f8384-a0d8-415e-8bd3-669c03335655/

Response :

{
    "status": "success",
    "message": "Design deleted successfully.",
    "data": {
        "design_id": "8e4f8384-a0d8-415e-8bd3-669c03335655"
    }
}
